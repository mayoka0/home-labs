# Contributing

Suggestions, documentation fixes, and carefully scoped improvements are welcome.

## Start with an issue

Open a GitHub issue to discuss larger changes before sending a pull request. Keep reports focused on reproducible behavior and avoid publishing private infrastructure details.

## Pull requests

- Explain the problem and the proposed change.
- Keep changes small and reviewable; this repository is documentation-only unless maintainers explicitly add and review code.
- Use placeholders such as `<your-domain>` and `<your-tailnet-host>`; use documentation-only example IP ranges.
- Never include real domains belonging to a private service, IPs, email allowlists, account IDs, tunnel IDs, tokens, passwords, private keys, cookies, QR codes, or unredacted screenshots/logs.
- Check the staged diff for secrets and machine-specific details before submitting.
- Do not add destructive, privileged, or auto-running setup commands without an issue discussion, a threat/safety review, and explicit maintainer approval.

By submitting a contribution, you agree that it may be distributed under this repository's GPL-3.0-only license.
