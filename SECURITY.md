# Security

This repository describes a personal home lab. Do not use it to publish credentials or sensitive operational details.

## Reporting a vulnerability

Please do not report suspected vulnerabilities, exposed credentials, or private infrastructure details in a public issue. Use GitHub's private vulnerability reporting for this repository if available; otherwise contact the maintainer through the GitHub profile and ask for a private channel.

Include only the minimum information needed to explain the issue. Do not test against systems or accounts you do not own or have permission to assess.

## If a secret was exposed

Removing a secret from the latest file is not enough if it was committed: revoke or rotate it immediately, then coordinate history cleanup. Assume exposed credentials may have been copied. Never paste the replacement credential into an issue or pull request.
